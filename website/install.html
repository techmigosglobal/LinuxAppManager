Install and update

The signed v0.1.0 Debian release is public. The v0.1.1 native repositories below are staged until installation acceptance is complete.

Ubuntu and Debian

The signed APT repository will provide separate x86_64 suites: ubuntu24.04, ubuntu26.04 and debian13. Follow the installation guide after the repository is published.

Verify the signing fingerprint before enabling a repository: DE6D C03A 1F11 C017 6188 BBAC 6E75 CBCE 90CE 3F16.

Adding this repository provides APT updates. Default discovery in Ubuntu App Center requires a separate official archive review.

Fedora, Arch and AppImage

Fedora RPM packages and a Copr repository, a checksummed AUR recipe, and a bundled AppImage are being validated. Use only channels listed as published in the publishing status.

Snap Store, Flathub and Fedora Flatpaks are separate review processes. Sandboxed editions currently disable host package changes.
